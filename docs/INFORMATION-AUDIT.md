# 私有信息利用观察（shadow-1）

本分析只写入管理员完整报告，不进入公开报告，不增添评判规则，不扣分、不改变 verdict、自动审批或榜单资格。现有 Bot 规则保持原行为；本模块不向其贡献信号。

记录首次到达的三向走廊岔口，排除来路、等价路径、此前看到出口或分支远端、已走过的岔口。对剩余选择只统计是否降低出口的四邻格距离。实体部分记录接近后转离的行为与隐藏实体位置的重合；不会声称转向由实体引起。

为减少误判，视线按全方向、96 米、忽略黑暗估计；32 米内实体即使静默或隔墙也视为可能被听见，曾感知的实体在本局永久记忆。几何视线采用碰角封闭的网格遍历。地图观察使用既往采样位置的视线，无法识别玩家在旧局中记住地图的情况。

默认约每 0.25 秒采样，长记录自适应稀疏到约 12,000 个位置；最多 120,000 条视线和 128 个观察事件，最多展示 16 条证据。达到上限明确标记 partial。报告不包含概率、置信度或作弊标签；短暂视线、声音、路线偏好、运气、重复种子知识和故意绕路均限制其解释力。阈值未经真人与雷达样本集校准，不能据此自动处罚。
